# 🧠 Neural Flashcards

An intelligent, interactive flashcard web application designed to help users study efficiently with an AI topic generator and a sleek, modern dark theme.

## ✨ Features

- **AI-Powered Generation:** Enter a topic and choose the number of questions to dynamically generate new study material.
- **Dark Mode Interface:** Designed with accessibility and comfortable reading in mind for late-night study sessions.
- **Subject Filtering:** Seamlessly switch between subjects or view your entire deck.
- **Progress Tracking:** Built-in progress bar and card counter.
- **Local Storage:** Progress and custom cards are saved automatically in your browser.

## 🛠️ Tech Stack

- **HTML5** - **CSS3** - **Vanilla JavaScript**
